# Reconstruction experiment

This experiment evaluates top-k reconstruction of held-out residual-stream
activations. Reusable implementation lives in `src/icalens/experiments`; this
directory records the paper runs that invoke the installed `icalens` CLI.

- `official/` contains the commands, results, and figures accepted for the paper.
- `pilot-runs/` contains local smoke tests, diagnostics, and superseded runs and is
  ignored by Git.

See `official/README.md` for reproduction instructions.
