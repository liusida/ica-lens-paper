RAVEL Cause vs. Isolation for each attribute test set. Each panel trains one mask for the named attribute; Cause pairs query that attribute and Isolation pairs query the other two attributes of the same entity type. SAEBench RAVEL on Gemma 2 2B (residual stream, layer 12), default configuration (top 500 entities, 5000 pairs per attribute, 2 epochs, mean of 2 seeds; whiskers show the range). Cause: fraction of interventions that switch the queried attribute to the source entity's value. Isolation: fraction of interventions that leave the entity's other attributes unchanged. Grey lines mark equal Disentangle = (Cause + Isolation) / 2. ICA, PCA and Random use sign-split coordinates of an exactly invertible basis; SAE is Gemma Scope 16k (average_l0_41).
