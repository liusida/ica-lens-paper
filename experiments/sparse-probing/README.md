# Sparse-probing experiment

This experiment evaluates feature concentration with the SAEBench sparse-probing
protocol. Reusable implementation lives in `src/icalens/experiments`; this
directory records the paper runs that invoke the installed `icalens` CLI.

- `official/` contains the commands, results, and figures accepted for the paper.
- `pilot-runs/` contains local smoke tests, partial runs, and superseded runs and
  is ignored by Git.

See `official/README.md` for reproduction instructions.
