# Superseded smoke evidence

These three smoke figures established that the TPP integration runs across all
three model families.  They are retained only as development evidence and must
not be used as experimental results: their unfitted-ICA control used QR
orthogonalization rather than the symmetric decorrelation used by ICA Lens at
FastICA iteration zero. These archived pilots used method-definition version 1;
the current ReLU-ICA protocol uses method-definition version 4.
