# 成分画像

ICA 方向是一条坐标轴，并不自带语义标签。成分画像为研究者提供证据，帮助提出并检验
成分标签。

画像与分析结果中的 token 卡片互为补充：

- token 卡片展示成分在**当前输入**上的表现；
- 成分画像总结它在**画像语料**上的整体表现。

## 画像如何生成

拟合完成后，ICA Lens 会让具有代表性的文本或对话数据流经每个已拟合层。这个过程不会
重新拟合或改变 ICA 方向。对于每个成分，画像会记录：

- 分数偏度、超额峰度，以及由偏度选择的尾部；
- 分数为正或为负的频率；
- 分数平方能量在正负两侧的分布；
- 具有代表性的高能量 token 位置及其上下文；
- 每个写入方向经过 Logit Lens 投影后对应的词表 token；
- 如果加入了兼容的 R-lens，还会记录写入方向经过后续模型近似映射后的词表 token。

画像保存在 ICA Lens 产物的 `component_profiles/` 目录中。画像数据集及其精确 revision
会与拟合来源分开记录。CLI 和 Python 工作流见[拟合与发布](fit-and-publish.md)。

## 阅读画像

在 token 卡片中选择一个成分，然后展开 **Component profile**。

![包含语料样例、Logit Lens 和 R-lens 读出的 ICA 成分画像](assets/component-profile-r-lens.png)

### 尾部选择

ICA Lens 根据偏度的正负选择要显示的尾部：正偏度选择正尾，负偏度选择负尾。偏度恰好
为零时，回退到分数平方能量较大的一侧。结果保存为 `tail_direction`，并为兼容性同步
保存为 `dominant_sign`。

### 统计量

对于成分分数 \(x_1,\ldots,x_N\)，记 \(\mu\) 为总体均值，\(\sigma\) 为总体标准差。
画像中显示的三个统计量是：

- **偏度（skewness）**衡量分布左右两侧的不对称程度。它的正负表示哪一侧尾部更突出，
  因而直接决定所选符号：

  $$
  \operatorname{skewness}(x)
  = \frac{1}{N}\sum_{i=1}^{N}\left(\frac{x_i-\mu}{\sigma}\right)^3.
  $$

- **超额峰度（excess kurtosis）**衡量分布产生极端分数的程度，但不区分正侧和负侧。
  高斯分布的超额峰度为零：

  $$
  \operatorname{excess\ kurtosis}(x)
  = \frac{1}{N}\sum_{i=1}^{N}\left(\frac{x_i-\mu}{\sigma}\right)^4-3.
  $$

- **Logcosh 偏差（logcosh deviation）**是 FastICA 排列成分 ID 时使用的非高斯性度量。
  对 \(M\) 个拟合得到的 ICA 坐标 \(y_1,\ldots,y_M\)，其定义为：

  $$
  \left|
  \frac{1}{M}\sum_{i=1}^{M}\log\!\cosh(y_i)
  - \mathbb{E}_{Z\sim\mathcal{N}(0,1)}[\log\!\cosh(Z)]
  \right|.
  $$

  标准高斯基线约为 \(0.374567\)。偏差越大的成分排在越前。由于这一对比函数与超额
  峰度不同，两者的排名不一定一致。

偏度和超额峰度由画像语料的分数计算；logcosh 偏差则在模型拟合时由拟合数据计算。
完整的符号频率与平方能量比例仍保存在画像数据中。

### Logit Lens token

这些 token 来自成分写入方向经过模型最终归一化层和反嵌入后的结果。它们提供第二类、
来自模型自身的线索，可以支持或质疑从语料样例中得到的解释。

对于中间层，这个投影跳过了所有后续 Transformer block。因此它只是诊断性关联，既不
预测模型将生成什么，也不能证明成分的含义就是某个列出的 token。

### R-lens token

R-lens 使用在语料上估计的平均线性映射，把成分的写入方向传到更靠后的残差流层，再经过
模型的最终归一化层和反嵌入。与直接 Logit Lens 相比，它近似纳入了中间 Transformer
block 的影响。

它仍然只是诊断性关联：该映射是语料平均结果，不是针对当前输入的精确因果效应。只有在
产物中加入兼容的 R-lens 后，这一行才会出现。

### 高能量样例

这些样例来自所选成分在对应 token 分数能量中占比较大的语料位置。高亮 token 是被选中
的位置，浅色文本是它的上下文。

应把多个样例放在一起阅读。反复出现的词语、主题、句法角色或篇章模式可以帮助提出
暂定标签。这份列表只包含筛选出的高能量样例，不是该成分的全部激活，也不是整个数据集
上的词频表。

## 提出暂定标签

可以按以下顺序阅读：

1. 先看所选尾部和高能量样例。
2. 寻找在不同上下文中反复出现的模式。
3. 比较 Logit Lens token，以及可用时的 R-lens token，是否支持这种解释。
4. 使用 `lens.analyze()` 在新输入上检验这个标签。

最终结果应被视为待检验的假设。画像可以显著加快标注，但其证据取决于画像语料，不能
替代在独立样例上的验证。
