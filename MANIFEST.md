# Repository Manifest

This repository contains the standalone ICA Lens code release.

Included in git:

- reproduction and verification code;
- model, activation, fitting, and analysis configs;
- artifact manifests and checksums;
- explorer application code;
- tests and documentation.

Excluded from git:

- fitted ICA tensors;
- explorer SQLite databases;
- reproduced activation captures;
- reproduced ICA models;
- generated result directories;
- local environments and caches.

Large public artifacts are fetched into `artifacts/fetched/`.
