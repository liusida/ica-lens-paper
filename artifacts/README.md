# Artifacts

Large files are not committed to this repository.

Expected downloaded layout:

```text
artifacts/fetched/models/
artifacts/fetched/databases/
```

The public artifact dataset is:

```text
sida/ica-lens-paper
```

The `models/` folder contains fitted ICA models and their sidecar metadata. The
`databases/` folder contains a miniature explorer database and a full explorer
database.
